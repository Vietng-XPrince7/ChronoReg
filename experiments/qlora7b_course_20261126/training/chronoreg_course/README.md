# ChronoReg 7B course snapshot experiment (not canonical release)
Same data, question format and LoRA hyperparameters as the 3B V2 experiment. Pinned Qwen2.5-7B-Instruct. Start with fresh adapter; no 3B transfer. One CUDA device only. GPU smoke performs one real optimizer step and three longest validation rows; smoke weights are discarded. Stage training saves a recoverable pending adapter before validation; only a fully validated stage joins the sequential chain. Validation loss is weighted by assistant tokens (not directly equivalent to prior Trainer eval_loss). Dataset caveats remain in dataset/manifest.json. Generation evaluation is lexical diagnostics, not frozen benchmark quality. Do not deploy until answer review. Output path separate from 3B. GPU code not tested in the build environment.
